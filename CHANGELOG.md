# Changelog

## v1.0 (2026-10-27)
- Split into the **base bracket** and the **45° adapter** add-on, each with its own folder.
- Base bracket **rev 2**: the side-pad screw pair moved to 1" apart, 22.5 mm up the side, so the pad counterbores clear the pad edge.
- Tapped holes cut as pilots for drilling before tapping: bracket Ø3.3 (drill #21, tap #10-24), adapter Ø3.2 (drill 3.5, tap M4).
- Pads: centre pad 7.75 mm (original 6.35 + 1.4 preload), side pads 6.60 mm with the rev-2 holes.

Before v1.0 (not published): rev 1 base bracket and v6 adapter, the production run, with Ø3.8 / Ø3.3 holes.
